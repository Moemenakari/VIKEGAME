# ⚔️ Jarlheim (VIKEGAME)

**A free, high-quality 3D mobile strategy game set in an original Norse world.**
Build your hold, recruit legendary heroes, forge a clan, hunt the Draugr,
and fight for the High Seat. The holder becomes King and appoints the realm's ministers.

> **Challenge #10:** a full 4X mobile strategy game, designed and engineered with **Claude Code**,
> using only free and open-source technology.

**Status:** 🧱 **M0: Foundations (pre-production).** No game code yet, on purpose:
the design and architecture come first.

## 🛠️ Tech stack (all free)
TypeScript · Three.js · React · Vite · Vitest · Playwright · Capacitor (Android) · GitHub Actions · GitHub Pages

## 🎨 Originality
The game's **mechanics** follow the conventions of the mobile 4X genre. All **art, characters,
names, audio and UI** are original or CC0, credited in `assets/CREDITS.md` (from M1).
